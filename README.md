## Overview

Full-stack monorepo built with a **Domain-Driven Design (DDD)** architecture and managed using **pnpm workspaces**.

The project combines **AdonisJS backend applications** with a shared **React design system** to ensure consistency, scalability, and code reuse across the ecosystem.

### Main Stack

- **Backend:** AdonisJS 6
- **Frontend:** React 19 + Inertia.js
- **Database:** PostgreSQL
- **Styling:** UnoCSS
- **Build Tool:** Vite 6
- **Package Manager:** pnpm 9
